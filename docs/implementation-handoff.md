## 実装時に維持する決定

- 区間は0始まりの整数小節、終了端を含まない。画面は1始まり。
- 同一レーンの重なり禁止、最小1小節、曲末を超えない。BPM変更で小節位置は動かさない。
- Pointer Eventsの一時プレビューと確定データを分離。純関数をテストする。
- JSONは唯一の永続化手段。アカウント、API、DB、自動保存を増やさない。
- JSONは検証に成功して置き換えを確定するまで現在のstateを変更しない。
- 任意文字列はReactのテキスト出力。ユーザーのメモをHTMLとして実行しない。
- 汎用UIはshadcn、タイムラインの位置計算と操作は独自実装。
- 認証・CI自動デプロイ・ドメイン設定を追加する必要はない。
